# 🚀 algo-self-study
> **매일 한 문제, 꾸준한 성장을 위한 알고리즘 **

---

## 📌 학습 목표
- [ ] 매일 최소 1문제 이상 풀이 및 업로드
- [ ] 풀이 후 효율적인 알고리즘(시간 복잡도) 고민 및 정리
- [ ] 틀린 문제는 반드시 오답 노트를 통해 원인 분석

## 🛠 기술 스택
- **Language**: Java 17+
- **IDE**: IntelliJ IDEA
- **Platforms**: 
  - [Baekjoon Online Judge](https://www.acmicpc.net/)
  - [SW Expert Academy](https://swexpertacademy.com/)
  - [Programmers](https://programmers.co.kr/)
